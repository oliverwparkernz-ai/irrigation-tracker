Database setup & security notes
In Firebase Console, enable Authentication → Sign-in method → Anonymous. Create a Realtime Database. For a small private team using a hard-to-guess invite link, these rules allow signed-in anonymous app sessions to read/write data:

{"rules":{".read":false,".write":false,"teams":{"$team":{".read":"auth != null",".write":"auth != null"}}}}

This is link-based access, not individual identity verification. Anyone who obtains the team link can edit the data. A stronger setup would use server-side invite-token validation.
